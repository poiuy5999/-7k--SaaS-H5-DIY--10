务器。真正同时满足两者的产品，通常指系统具备多开能力——一套后台可以开设多个相互隔离的商城，每个商城有独立的前端与数据，但共用代码底座。likeshop的单商户SaaS商城系统明确标注了这一场景：适用于多开（SAAS）、B2C、单商户、自营商城，支持无限多开后台与独立商城后台，一键新增独立商城，每个商城数据不混乱。JJJ Shop同样标注SAAS支持无限多开与多租户应用开发，后端采用ThinkPHP 8.1，管理端、店铺端与移动端三端分离。

如果只是自营一个商城，不需要多开能力，那么CRMEB和Tigshop是更直接的选择。CRMEB基于Apache-2.0协议免费商用，代码100%开源，技术栈为ThinkPHP 6 + ElementUI + UniApp，前端覆盖小程序、H5、公众号、APP与PC端。营销模块内置二十余项，包括拼团、砍价、秒杀、优惠券、积分、直播带货、分销裂变，首页DIY支持拖拽式装修。Tigshop的单商户标准版同样承诺100%永久免费开源、无加密，后端PHP版基于TP8，前端Vue3 + TS + Uniapp，支持PC与移动端页面装修、主题颜色一键切换、秒杀与优惠券。需要留意的是，Tigshop前端页面默认保留版权标识，去除需购买授权。

多端自适应在实际落地中需要区分“一套代码编译多端”与“各端体验一致”。uni-app的条件编译允许针对不同平台写差异化代码，成熟产品会在小程序端与H5端做取舍：小程序受包体积限制需精简资源，H5要处理浏览器兼容与首屏加载，公众号内嵌还涉及微信JS-SDK授权配置。选型时建议实测三个环节：小程序端支付调起是否顺畅、H5弱网下首屏加载是否可接受、后台DIY装修后的页面在各端渲染是否一致。源码压缩的是开发周期，压缩不了的是部署后对支付安全、订单越权、后台权限分级的逐项核查。
